# Brazilian E-Commerce Analytics – Olist Dataset

## Project Overview

This project focuses on analyzing the Brazilian E-Commerce Public Dataset (Olist) to understand business performance, customer behavior, order cancellations, and delivery operations.

The project extends my SQL-based analysis into an interactive Power BI dashboard, transforming raw e-commerce data into meaningful business insights that support data-driven decision-making.

## Business Objectives

- Analyze overall e-commerce business performance.
- Understand customer distribution and geographic patterns.
- Identify order cancellation trends.
- Evaluate delivery performance and delays.
- Present key business metrics through interactive dashboards.

## Dataset

**Source:** [Brazilian E-Commerce Public Dataset – Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains Brazilian e-commerce transaction data covering the period from 2016 to 2018.

The project uses five core datasets:

- Orders
- Order Items
- Customers
- Products
- Order Payments

## Tools & Technologies

- **SQL Server:** Data querying and business analysis.
- **Power BI Desktop:** Data visualization and interactive dashboard development.
- **DAX:** Business calculations and analytical measures, where applicable.

## Dashboard Pages

The Power BI report contains four analytical pages:

### 1. Executive Overview
Provides a high-level view of overall e-commerce business performance through key metrics and visualizations.

### 2. Customer & Geographic Insights
Explores customer distribution and geographic patterns to understand the platform's customer base.

### 3. Cancellation Analysis
Examines order cancellations to identify patterns and understand potential areas of business improvement.

### 4. Delivery Performance
Analyzes delivery performance to understand delivery timelines and operational efficiency.
